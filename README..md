# Cybersecurity Data Analysis and Machine Learning Workflow

## Project Overview

This project focuses on data cleaning, exploratory data analysis (EDA), visualization, and a supervised machine learning workflow using a cybersecurity dataset in Python.

The objective of the project was to understand the structure of cybersecurity data, identify patterns and trends, visualize feature distributions, and implement a basic predictive modeling workflow.

The project demonstrates practical applications of:

* data preprocessing
* exploratory data analysis
* visualization techniques
* supervised learning workflows
* model evaluation methods

---

# Features

## Data Cleaning

* Removed duplicate records
* Handled missing values
* Removed low-value and redundant columns
* Processed categorical and numerical data

## Exploratory Data Analysis

* Statistical summaries using Pandas
* Feature distribution analysis
* IP frequency analysis
* Numerical feature visualization
* Correlation analysis

## Machine Learning Workflow

* Label encoding for categorical data
* Train-test split
* Decision Tree and Random Forest workflow
* Accuracy evaluation
* Confusion matrix visualization

# Exploratory Data Analysis

The following analyses and visualizations were performed:

* Severity distribution analysis
* Abuse confidence score distribution
* Top IP frequency analysis
* Boxplot analysis for numerical features
* Statistical summaries and dataset inspection

## Key Findings

* Numerical features showed low variance
* Severity values remained mostly constant
* Abuse confidence scores were concentrated near 100
* IP addresses appeared largely unique
* Several time-related features contributed minimal analytical value

# Dataset Limitation

The dataset exhibited limited class diversity and low feature variance, reducing its suitability for meaningful predictive modeling.

The machine learning section of this project was implemented primarily as a workflow demonstration to showcase preprocessing, training, and evaluation techniques.
